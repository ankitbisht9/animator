## Every scene stands on its own

Scenes are drawn independently and at the same time, so each one starts from an empty stage and shows everything it needs: use `transition` "fade" (or "cut" for a hard change), and leave `objects_kept` and `objects_removed` empty. Keep the lesson visually consistent anyway: when the same thing appears in several scenes, give it the same id and describe it the same way each time (same place on the stage, same size, same colors), so it reads as the same object.
